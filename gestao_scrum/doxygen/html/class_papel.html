Detailed Description

Dominio que representa o papel (role) de uma pessoa no projeto.

Valores validos (unicos aceitos): "DESENVOLVEDOR", "MESTRE SCRUM", "PROPRIETARIO DE PRODUTO".

Exemplo valido: "MESTRE SCRUM". Exemplos invalidos: "GERENTE", "desenvolvedor".
