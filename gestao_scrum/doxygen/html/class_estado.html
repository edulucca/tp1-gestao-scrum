Detailed Description

Dominio que representa o estado de uma historia de usuario.

Valores validos (unicos aceitos): "A FAZER", "FAZENDO", "FEITO".

Exemplo valido: "FAZENDO". Exemplos invalidos: "EM ANDAMENTO", "feito".
