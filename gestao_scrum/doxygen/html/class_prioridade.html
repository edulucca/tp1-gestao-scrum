Detailed Description

Dominio que representa a prioridade de uma historia de usuario.

Valores validos (unicos aceitos): "ALTA", "MEDIA", "BAIXA".

Exemplo valido: "ALTA". Exemplos invalidos: "URGENTE", "alta".
